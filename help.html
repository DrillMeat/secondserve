Getting Started

Welcome to PharmaT Audit! This guide will help you get up and running quickly.

First Steps

  1. Complete Your Profile: Fill in your professional information for better audit recommendations
  2. Explore the Dashboard: Familiarize yourself with the main interface
  3. Create Your First Audit: Use the "Start New Audit" button to begin
  4. Invite Team Members: Add colleagues to collaborate on audits
Tip: Start with a simple internal audit to get familiar with the platform before conducting external audits.

System Requirements

  • Modern web browser (Chrome, Firefox, Safari, Edge)
  • Stable internet connection
  • JavaScript enabled
  • Minimum screen resolution: 1024x768

Dashboard Overview

The dashboard is your central hub for managing all audit activities.

Key Components

  • Statistics Cards: Quick overview of active audits, completed audits, compliance scores, and pending reviews
  • Recent Audits: List of your most recent audit activities with status indicators
  • Quick Actions: Fast access to common tasks like starting new audits and generating reports
  • Navigation Menu: Access to different sections of the platform

Status Indicators

  • In Progress: Audit is currently being conducted
  • Completed: Audit has been finished and report generated
  • Pending: Audit requires review or action

Managing Audits

Learn how to create, manage, and track your pharmaceutical audits.

Creating a New Audit

  1. Click "Start New Audit" from the dashboard
  2. Select audit type (GMP, GDP, GCP, etc.)
  3. Fill in audit details and scope
  4. Assign team members and reviewers
  5. Set schedule and milestones
  6. Launch the audit

Audit Types Supported

  • GMP (Good Manufacturing Practice): Manufacturing facility audits
  • GDP (Good Distribution Practice): Distribution and supply chain audits
  • GCP (Good Clinical Practice): Clinical trial audits
  • Pharmacovigilance: Drug safety monitoring audits
  • Quality System: Overall quality management system audits
Important: Ensure all audit team members have appropriate access permissions before starting an audit.

Troubleshooting

Common issues and their solutions.

Login Issues

  • Verify your email address and password
  • Check if your account has been activated
  • Clear browser cache and cookies
  • Try using a different browser

Performance Issues

  • Check your internet connection
  • Close unnecessary browser tabs
  • Disable browser extensions temporarily
  • Try refreshing the page

Data Sync Issues

  • Ensure you have a stable internet connection
  • Check if you have the necessary permissions
  • Try logging out and back in
  • Contact support if issues persist
